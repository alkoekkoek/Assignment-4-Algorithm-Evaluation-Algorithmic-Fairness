# Assignment-4-Paper-Review-and-Algorithm-Evaluation-Algorithmic-Fairness
For this assignment I evaluate the effectiveness of the the bias-mitigation algorithm reweighting as described by Kamiran and Calders (2012).

## Downloading the data
I evaluated the effectiveness of reweighting on three datasets, which are downloaded in the python notebook with code from the following websites:
- **Adult Census Income**: https://www.kaggle.com/datasets/uciml/adult-census-income
- **German Credit Data**: https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data
- **COMPAS Recidivism Racial Bias**: https://www.kaggle.com/datasets/danofer/compass

## References
Kamiran, F., & Calders, T. (2012). Data preprocessing techniques for classification without discrimination. Knowledge and Information Systems, 33(1), 1–33. https://doi.org/10.1007/s10115-011-0463-8
